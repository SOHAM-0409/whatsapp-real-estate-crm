# 🏠 WhatsApp Real Estate CRM

A free, zero-cost WhatsApp CRM dashboard for real estate agencies in India.
Built with React, Google Apps Script and WhatsApp Deep Links.

## ✨ Features
- Live lead capture from Google Sheets
- AI-powered reply drafting based on property interest
- WhatsApp deep link — pre-filled messages in one click
- Bidirectional Sheet sync — replies saved back automatically
- Works offline — single HTML file, no install needed
- Hindi + English language support

## 🚀 How to use
1. Download `index.html`
2. Open in any browser
3. Paste your Google Apps Script URL in the modal
4. Start managing leads instantly

## 🔧 Google Sheet Setup
See `google_apps_script.js` — deploy as a Web App with access set to Anyone.

Required columns: Name · Phone · LastMsg · Interest · Status · Time · LastReply · RepliedAt

## 💰 Zero Cost
- No monthly fees
- No server needed
- No app to install
- Data stays in your Google Sheet — you own it
